# RPG Game : Hero vs Devil

A simple fantasy RPG desktop game built with Python and PyQt5, inspired by isekai-style battle systems.
The game focuses on strategic decision-making rather than complex mechanics.

Players control a Hero and must choose the right skill to defeat the Devil.
Each skill has strengths and weaknesses, making every battle unpredictable and engaging.

🎮 Gameplay Overview

The Hero has three unique fantasy skills:

🗡 Holy Blade
A balanced and reliable attack with stable damage.

❄ Frost Dominion
Deals lower damage but weakens the Devil’s attack, useful for long-term survival.

🔥 Inferno Cataclysm
A high-risk, high-reward skill that deals massive damage but also harms the Hero.

The Devil will counterattack after every turn, so victory depends on strategy, timing, and risk management — not luck alone.
